# Cultiva+ 
Projeto Controle de Defensivos Agrícolas

## 📌 Sobre o projeto

O **Projeto Controle de Defensivos Agrícolas** tem como objetivo desenvolver um sistema para auxiliar agricultores no gerenciamento de defensivos utilizados na propriedade rural.

A aplicação permitirá realizar o **controle do estoque de defensivos**, registrar e acompanhar as **aplicações realizadas em cada talhão**, além de manter um histórico das operações realizadas.

Dessa forma, o sistema busca facilitar a organização das informações, auxiliar o agricultor no **cumprimento das exigências relacionadas ao registro e controle das aplicações** e contribuir para a **redução de desperdícios e prejuízos** decorrentes do uso inadequado ou do controle insuficiente dos produtos.

## 🎯 Objetivos

- Controlar o estoque de defensivos agrícolas;
- Registrar entradas e saídas de produtos;
- Cadastrar e gerenciar os talhões da propriedade;
- Registrar as aplicações realizadas em cada talhão;
- Manter um histórico das aplicações;
- Facilitar o acompanhamento do uso dos defensivos;
- Auxiliar na organização das informações necessárias para o cumprimento da legislação;
- Contribuir para a redução de desperdícios e prejuízos.
